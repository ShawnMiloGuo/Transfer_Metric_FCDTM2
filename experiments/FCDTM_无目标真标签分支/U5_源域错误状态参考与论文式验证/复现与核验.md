# U5复现

服务器原仓库FCDTM环境。code/verify.py unit → prepare.py → launch.py。每个worker由strace记录实际文件打开；使用U0已验证的源annotation白名单审计，另由U5 Python/GDAL阻断评价数据路径，只允许当前源模型的U0参数及无标签缓存。主进程只处理输入哈希，worker不读取其他模型源统计。

全部成功后seal，再verify.py final，最后evaluate.py。finish.py仅等待成功封存后串行核验、评价绘图。禁止覆盖已封存预测。所有worker输出、源状态支持/原型/校准、target无标签缓存与日志独立存U5。

对照风险来自U0当前源模型的无标签缓存；新推理逐图bits必须与U0一致。新hard/soft每图重新计算源64图真实前景原型。目标真值只在evaluate读取。评价生成描述性相关与图，不反向调参数。原式hard横轴非AD，不画1:1线；预测AD画1:1，负AD保留，常量相关N/A。

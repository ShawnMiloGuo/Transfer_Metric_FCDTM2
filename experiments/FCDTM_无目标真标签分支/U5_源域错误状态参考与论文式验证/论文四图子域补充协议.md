# 按原论文每批4图核对的补充协议

原文main.tex“Measuring Feature Differences”明确N_k=4，且子域随机划分。U5初稿把一图当子域，这不是原文的批级口径；单图预测与评价保留为敏感性，主论文式验证改为每批4图。发现时原单图自动评价已结束，因此这是公开开发池上的口径纠正，不声称事先预注册或独立确认；没有据目标结果调整模型、原型、概率校准或分数方向。

每域先按图名排序，再用固定种子250117+域序号随机排列40图，连续每4图为一子域，形成10个不重叠子域；所有候选/类别使用相同分组，不看标签或精度选择分组。预测阶段只读取原U5封存的源参数及无标签缓存，禁止annotation及任何评价CSV；汇总四图期望TP/FP/FN再转F1，不平均图级F1。hard/soft也先汇总特征sum/mass再算分数。

四图预测再次封存，独立评价入口之后才读取四图真值；真F1同样先汇总真实计数。最多50×10=500散点。每固定模型/类别/方向跨10子域计算Pearson和Spearman，常量或不足3有效点N/A。输出四分组总览和50任务图。共同任务均值以所有主控制方法共同有限且相关可定义任务为准，同时保留自身覆盖。

主表必须包含conditional_margin，避免把预测侧拆分收益误算为距离/权重贡献。原式hard只作原生分数相关；AD MAE只报有AD单位的方法。图式沿论文，当前比较方法非FD/DS/GBC完整复现。每批4图也不等于独立地理区域；K=10的相关估计不作稳定性或显著性保证。

# U6复现与核验

在服务器FCDTM环境，保留U0及U5只读依赖。顺序：

1. `python code/verify.py unit`：已知混合比例、退化参考与空预测侧测试。
2. `python code/prepare.py`：冻结预测代码、协议和依赖哈希；已存在manifest时禁止覆盖。
3. `python -u code/launch.py`：8进程/每进程2 CPU线程；25个模型不微调，所有原生文件访问记录在logs；全部访问审计通过才生成seal。
4. `python code/verify.py final`：不用目标标签，以独立最小二乘解复算5200个混合预测；通过才评价。
5. `python code/evaluate.py`：唯一会读取目标标签的模块。plots.py和report.py只消费封存后数据。预测前已记录三者哈希，评价后review.py再次核对。
6. `python code/review.py`：独立重算540项误差汇总、1200项相关，核对U5同组真值和对照预测，验证58对PNG/PDF存在。

`code/finish.py`是本次后台顺序调度器，等待seal，不启动或改变预测。步骤3已运行时不重复启动；没有seal或审计失败时不得提前评价。

只读依赖U0：source参数、manifest、common及audit；U5：固定错误原型和无标签风险缓存。每worker按当前源模型过滤依赖、只准自己的源真标签。完整模型checkpoint及原始遥感数据仍位于原服务器，不复制到GitHub。artifacts/source包含源采样直方图和参数；unlabeled_cache包含目标无标签直方图、bits和固定采样bin索引，可复算预测及进行封存后的机制诊断。

8/16/24指无标签目标影像数。独立确认尚需按U4核对未参与设计网格与模型训练角色，本轮保持U5历史池做配对开发验证。禁止将本轮高相关或低MAE当作新区域泛化证明。

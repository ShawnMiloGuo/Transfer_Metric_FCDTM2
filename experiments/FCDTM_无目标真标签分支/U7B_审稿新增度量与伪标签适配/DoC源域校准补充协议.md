# DoC 原生差值与完整源域回归适配

本补充在全部预测完成及打开任何本轮目标参考之前固定。17项原生/适配方法保留；额外加入DoC-Acc-SrcCal，区分原始置信差分量与含源辅助任务回归的完整性能估计步骤，合计18项。它预测pixel accuracy，不冒充foreground F1。

仅使用每个候选自己的64张源参考图的缓存概率、预测和source_y；沿用OTCE相同的16个拟合、8个网格索引分离的源辅助四图任务。full2048和shared256分别保持同面板的源/辅助像素预算，不能使用其他模型源数据拟合当前候选。

以源平均最大置信度减辅助组平均最大置信度为输入、辅助源像素准确率为输出，标准化后进行含截距的一维岭回归，lambda=1e-3固定。源核验仅报告，既不按目标结果改系数，也不裁剪外推预测。预测前的augment_doc_sourcecal.py保留原差值及原始封存，新增分数后重新封存；只允许后续独立评价器读取目标参考。所有源拟合/核验记录及系数归档。

shared256正式配对包含18项，full2048包含16项（OTCE/MMD在共享上限面板比较）。此前17项预测代码、原始工作进程输出均不覆盖，本扩展以单独代码哈希、源校准记录和封存清单追踪。
